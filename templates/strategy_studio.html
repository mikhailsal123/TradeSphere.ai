Market commands
  • price("TICKER") — latest close (cached for the run)
  • buy("TICKER", shares) — paper buy; blocked if cash < cost
  • sell("TICKER", shares) — paper sell; blocked if you don't hold enough
  • position("TICKER") — shares currently held
  • cash() — remaining cash in the run
  • log(...) / print(...) — write to the console
Control flow
  • if condition: … — runs once if true
  • for i in range(N): … — runs N times
  • while condition: … — runs until false (or 5 s / 50,000 op safety limit)
Tab on empty editor inserts the example · Tab after typing autocompletes commands · Ctrl/⌘+Enter executes
